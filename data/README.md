# Eğitim verileri

- `toy/`: tamamı sentetik, küçük öğretici veri setleri; gerçek kişi/kurum verisi değildir.
- `wdi/`: R Programlama Kitabı için hazırlanmış Dünya Bankası WDI verilerinden ders amaçlı alt kümeler.

Verilerin kullanım amacı, yıl kapsamı, kaynak ve sınırlılıklar için depo kökündeki [DATA_PLAN.md](../DATA_PLAN.md) dosyasına bakın.

RStudio projesi açıkken yolları proje köküne göre kullanın: `data/toy/personel.csv`.
