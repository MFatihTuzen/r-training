# 09 · API, SDMX ve Veri Tabanı — Ek Egzersizler

1. CSV dosyası URL'si ile API uç noktası arasındaki farkı açıklayın.
2. Bir veri kaynağında URL, tarih, lisans, API sürümü ve gösterge tanımını neden kaydetmeliyiz?
3. `jsonlite::fromJSON()` ile üç değişkenli örnek JSON'u okuyun.
4. İsteğe bağlı `DBI`/`RSQLite` örneğini çalıştırın ve SQL koşulunu değiştirin.
5. SDMX verisinde gözlem değeri, boyut ve kod listesi farklarını kendi sözcüklerinizle anlatın.
6. API anahtarlarının neden public GitHub reposunda tutulamayacağını açıklayın.
